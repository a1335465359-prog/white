# AI 批量服装白底图工具 (Apparel White Background Tool)

这是一个简单、高效、可运行的**批量服装白底图精修工具**。用户可以一次性批量上传约200张服装商品图，系统会安全调度队列、自动管理高并发，并逐张调用高画质图像精修模型，将原图处理为干净、专业的纯白底（`#FFFFFF`）电商白底图。

## 🌟 核心特色与架构

1. **高保真工艺精修**：这不是简单的抠图，也不是重新设计服装。内置提示词指示模型**只允许优化背景、服装平整度和画面整洁度**，100%保留原服装的版型、面料纹理、色彩与工艺细节。
2. **安全进程内存 Key 存储**：API Key 仅存于运行中服务器的临时进程内存内，绝不写入数据库、localStorage、日志、配置文件。服务重启后会自动失效以保护隐私。
3. **高并发与指数退避任务队列**：
   - 默认同时并发处理 5 张，支持 1～20 范围动态调整。
   - 单张 180s 接口超时保护。
   - 遇到频控 429 或 5xx、网络超时等错误会自动按 **5秒、15秒、45秒** 指数级延时加小幅随机抖动重试 3 次，单张失败绝不中断其他图。
   - 暂停时只停止派发新任务，正在请求中的图会完整运行并下载。
4. **模型结果本地物理转存**：如果模型返回临时图片 URL、Base64 或 Data URL，服务端会立即将其**安全下载转存到本地磁盘目录**（`storage/processed`），并通过受保护的 `/api/files` 路由读取，绝不直接使用不稳定的临时外链。
5. **极其强壮的解析器 (imageApi)**：集中封装，兼容并支持提取**图片 URL、Base64 字符串、Data URL、Markdown图片链接、多层嵌套 Response 内置图片对象**。
6. **主图 + 细节图工作流**：成功主图可按需生成领口、袖口、口袋、下摆等独立白底细节图；支持选择多个商品和多个部位批量生成，细节图和主图共享同一个并发与重试队列。
7. **重新生成与版本清理**：主图可一键重新生成；旧主图及关联细节图会被清理，避免新旧版本混用。
8. **多项人性化功能**：总进度条、分类过滤筛选、单张/一键重试失败项、单张下载及**一键打包主图和细节图 ZIP 下载**。
9. **流畅预览设计**：缩略图全流程配置 `loading="lazy"` 懒加载，细节图采用横向滑动预览，防一次性加载 200 张大尺寸图片导致网页卡顿或崩溃。

## 🛠️ 技术选型

* **前端**：Next.js (App Router), React, Tailwind CSS, Lucide Icons, JSZip (前端纯内存打包)
* **后端**：Next.js Route Handlers (API 路由)
* **数据库**：PostgreSQL (连接在 `.env` 中) + Drizzle ORM
* **图像模型**：`gemini-3.1-flash-lite-image` (固定写入，底座由 12ai.org 统一代理分发)
* **接口 Base URL**：`https://new.12ai.org`

## 🚀 快速启动指南

### 1. 确保环境变量

项目连接了本地 PostgreSQL 实例。请检查或配置项目根目录下的 `.env` 文件：

```env
DATABASE_URL=postgresql://postgres:postgres@127.0.0.1:5432/app_db
```

### 2. 数据库同步推模型

在首次启动前，直接使用 Drizzle-Kit 将定义的任务表推入 PostgreSQL：

```bash
npx drizzle-kit push
```

### 3. 安装依赖与启动服务

```bash
# 1. 确保安装完毕
npm install

# 2. 编译生产版本
npm run build

# 3. 运行生产环境
npm run start
```

访问本地服务：`http://localhost:3000`

## 💡 使用步骤说明

1. **输入 API Key**：在页面顶部输入您在 `12ai.org` 的 API Key，点击“保存 Key”进行校验与内存存储。
2. **选择/拖拽服装图**：直接将不超过200张的服装图片（JPG, JPEG, PNG, WEBP）拖入虚线上传框，或者点击选择。
3. **（可选）微调提示词与并发数**：
   - 默认提示词针对衣服抗皱、去除衣架人物模特及纯白棚拍进行了长篇定制，如果您需要额外微调，可展开“处理提示词”进行编辑。
   - 随意调大或调小并发度（1-20，默认5）。
4. **开始生成主图**：点击“开始生成白底图”，系统会优先自然整理明显运输折痕、衣架压痕和杂乱堆皱，同时保留服装的真实纹理与自然垂坠。
5. **查看、细节图与重新生成**：
   - 点击任意商品卡片，可对比原图、白底主图，并左右滑动查看领口、袖口、口袋、下摆细节图。
   - 成功主图可点击“批量细节图”：勾选一个或多个部位，再横向勾选需要处理的商品，点击确认即可批量入队。
   - 若主图效果不理想，点击卡片上的回转图标或预览内的“重新生成”；系统会删除该图旧细节，避免混用。
   - 如果发生失败，可点击对应的卡片“重试”。
6. **保存与打包**：单张可直接保存；点击“保存全部”会在浏览器本地生成 ZIP，其中分别包含 `白底主图/` 与 `细节图/` 目录。
7. **重置**：处理完当前批次，点击“一键清空重置工作区”，系统会同步物理清空磁盘和数据库，开启下一批次的无感创作！

## 🐘 无系统 PostgreSQL 环境（如 Arena 沙箱）的本地数据库

若环境里无法通过 `apt` / Docker 安装 PostgreSQL，项目依赖里已内置 Linux x64 的
PostgreSQL 二进制（`@embedded-postgres/linux-x64`），可直接启动一个本地实例：

```bash
# 1. 安装依赖（会自动带上嵌入式 PostgreSQL 二进制）
npm install

# 2. 启动本地 PostgreSQL（默认 127.0.0.1:5432，数据目录 ./.pgdata）
./scripts/start-db.sh
```

然后按上面的流程：创建数据库 → `npx drizzle-kit push` → `npm run build` → `npm run start`。
